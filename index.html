02

Building With AIshipped products, not documents

The short version

I use AI to build and ship real products, not to write faster documents. Six model surfaces run in production inside PitStop, and sixty probes decide whether any of them is telling the truth.

Extraction

Reads Any Document

A customer photographs a creased bill from another garage. A supplier answers an enquiry with a PDF. No template and no field map: the model turns the page into rows, and plain code does every number that has to be right.

Agent loops

Tools, Not Prompts

Two conversation loops with tool use. The dangerous tools are not refused, they are absent, and every query runs under the signed-in human's own row security rather than the model's good intentions.

Verification

One Line in Five Is a Check

Sixty probes driving real HTTP, real websockets and real sessions. One of them reads the project's own documentation and fails when the database disagrees with it.

Where PitStop’s 94,129 lines went
  • Product code 63,716
  • Schema 13,296
  • Checks 17,117

Counted this morning, not estimated. The whole technical story is its own page: the six model surfaces, how a photographed bill becomes a row, why none of it can be steered by what is written on the page, and the four things I cannot yet prove.
