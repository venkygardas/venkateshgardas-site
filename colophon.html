About this site

Colophon

Plain HTML, a 2px ink grid, and one blue.

Spec
Stack
HTML and one stylesheet. No framework, no build step
Type
Archivo, Instrument Sans, Space Mono
Hosting
Cloudflare Pages, deployed on push
Design debt
The layout logic owes a debt to C40's grid

This site was designed and built in conversation with Claude, who also drew the hands on the homepage. The words describe real work and real products, and the opinions are all Venkatesh's.

The rules the site is built under: no framework, no build step, no drop shadows, no gradients, no border radius, and text you can read at arm's length. The grid is a 2px ink line and everything lives inside it.
