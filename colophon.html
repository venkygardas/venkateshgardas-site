About this site

Colophon

Plain HTML, one stylesheet, and a garage that never stops working.

Spec
Stack
HTML and one stylesheet. No framework, no build step
Type
Poiret One, Inter Tight, Space Mono, self-hosted. Syne on the bench
Hosting
Cloudflare Pages, deployed on push
Design debt
The first design owed C40’s grid. This one owes Arounda’s port concept

This site was designed and built in conversation with Claude, who also drew the animated garage on the homepage. The words describe real work and real products, and the opinions are all Venkatesh’s.

The rules the site is built under: no framework, no build step, no third-party requests, and text you can read at arm’s length. The current look is the second design system this site has worn; the first, a flat 2px ink grid on paper, lives on in the git history. Both were measured against the same accessibility numbers before shipping.
